Technical Report: Property System & Import/Export — العمودي للتسويق العقاري
1. Architecture Overview
The system is a full-stack real-estate platform with two tiers:

Layer	Technology	Location
Frontend	React + Vite (TypeScript)	artifacts/alamoudi/src/
Backend	Express 5 (TypeScript)	artifacts/api-server/src/
Database	PostgreSQL via Drizzle ORM	lib/db/src/
State Management	React Context (DataContext)	artifacts/alamoudi/src/context/DataContext.tsx
All data mutations go through optimistic updates: the frontend updates local state immediately, then calls the API in the background. If the server rejects the request, the error is shown and data is re-synced.

2.4 Insert Validation (Backend — insertPropertySchema)
The schema is auto-generated from the Drizzle table definition using drizzle-zod's createInsertSchema. This means:

id, code are required strings.
All other columns with .default(...) are optional at insert time; the DB default is applied if omitted.
The import endpoint (POST /api/properties/import) validates via z.array(insertPropertySchema).
The create endpoint (POST /api/properties) validates via insertPropertySchema.
The update endpoint (PATCH /api/properties/:id) validates via insertPropertySchema.partial() (all fields optional).

7.2 Excel Import Flow (parseWorkbookBytes)
Entry point: parseWorkbookBytes(bytes: Uint8Array): ParseResult

Step-by-step:

Parse workbook with XLSX.read(bytes, { type: "array" }).
Iterate each sheet in wb.SheetNames.
For each sheet, convert to a 2D array via XLSX.utils.sheet_to_json(sheet, { header: 1, defval: "", raw: false }).
Extract sheet metadata (sheetMeta(sheetName)) — determines regionId, regionName, and category purely from the sheet name using regex patterns.
Find header row (findHeaderRow) — scans the first 6 rows looking for a row that contains both "النوع" and "الكود". Returns the row index.
Map column indices using HEADER_FIELD (legacy direct-name map) — each recognized Arabic column header is mapped to an internal field name.
Parse data rows starting from headerIndex + 1:
Skip numbering rows (rows where all non-empty cells are # or pure digits).
Skip repeated header rows (rows that again contain النوع and الكود).
Call rowToProperty() to extract one ParsedProperty from a row.
Skip rows with no meaningful data (unitType, code, subArea, area, layout, price all empty).
Return { items: ParsedProperty[], sheets: { name, count }[] }.

7.3 CSV / TXT Import Flow (parseDelimitedText)
Entry point: parseDelimitedText(text: string, regions: RegionLite[], types: RegionLite[]): ParseResult

Step-by-step:

Strip BOM (\uFEFF) if present.
Parse with the custom splitCsvIntoRows() function — handles quoted fields with embedded commas, newlines, and escaped double-quotes (""). Supports both comma (,) and tab (\t) as delimiters.
Row 0 = headers — each header string is passed through the smart alias mapper (mapHeader / ALIAS_TO_FIELD).
Extract data rows (row 1 onwards) — skip fully empty rows and rows without code, title, price, or area.
For each row: resolve region, category, typeId, status, featured, agentType, and all numeric fields.
Return { items, sheets: [{ name: "ملف", count: items.length }] }.
Smart Header Alias System (FIELD_ALIASES map, normalised):

The CSV parser uses a much broader alias table than the Excel parser, supporting both Arabic and English column names. The normalisation strips Arabic diacritics (harakat), collapses whitespace, and lowercases. Recognised aliases per field:

Technical Report: Property Management System
Al-Amoudi Real Estate Platform (العمودي للتسويق العقاري)
1. System Architecture Overview
The platform is a fullstack TypeScript monorepo with two main artifacts:

Layer	Location	Technology
Frontend SPA	artifacts/alamoudi/src/	React + Vite + Wouter + TanStack Query
Backend API	artifacts/api-server/src/	Express 5, Node.js ESM

All data flows through a single global React context (DataContext) that uses an optimistic-write strategy: state is updated locally first, then a background persist() call syncs to the API. On API failure, the context re-fetches from the server to correct any drift.

Optimistically added to local state
POST /api/properties sent in background with full payload
API validates with insertPropertySchema (Zod) and inserts into DB

8.3 Excel Import Pipeline
Entry point: parseWorkbookBytes(bytes: Uint8Array): ParseResult

category from sheet name: إيجار/ايجار → rent, مفروش → furnished, else → sale
Locate header row — findHeaderRow() scans the first 6 rows looking for a row containing both "النوع" and "الكود"
Skip numbering rows — isNumberingRow() skips rows where all cells are numeric or #
Map headers to fields — HEADER_FIELD dictionary (Arabic column names → internal field names):
Arabic Header	Internal Field

Parse each data row — rowToProperty():
Skips rows with no data in any of: unitType, code, subArea, area, layout, price

Per-row parsing:

8.5 Region Resolution for Unmatched Rows
During the preview step, properties with an empty regionId are flagged. The admin can choose a fallback region from a dropdown; this region is applied to all unresolved rows before confirming the import.

8.6 Import Upsert Logic (Deduplication)
The key is the code field:

Client-side (DataContext.importProperties()):

Builds a Map<code, index> of existing properties
For each incoming item: if code matches an existing entry → update (merge); else → insert (new id + createdAt)
All resulting records are sent in a single POST /api/properties/import call
Server-side (POST /api/properties/import):

Validates the entire array with z.array(insertPropertySchema)
For each item: queries WHERE code = item.code LIMIT 1
If found → UPDATE ... SET all_fields WHERE id = existing.id (id from incoming record is discarded)
If not found → INSERT
Returns { added: number, updated: number }

10. Backup and Restore System
Located at /admin/backup → Backup.tsx.

10.1 How It Works
Backup is client-side only — it reads directly from localStorage, not from the API. This means it captures the in-browser cached state, not necessarily a live server snapshot.

Keys backed up:

alamoudi_regions
alamoudi_property_types
alamoudi_properties
alamoudi_users
alamoudi_inquiries
alamoudi_finishing_requests
alamoudi_property_requests
alamoudi_settings
alamoudi_favorites
alamoudi_compare

Export: Serializes all keys to a single JSON object with exportedAt and version: "1.0", downloaded as alamoudi-backup-YYYY-MM-DD.json.

Restore: Reads uploaded JSON file, iterates the same key list, and writes each key back to localStorage, then reloads the page.

Reset: Removes all keys from localStorage and reloads the page.

Important limitation: The Backup/Restore operates on the browser's localStorage cache. The primary data store is the PostgreSQL database, which is managed through the API. The backup does not directly dump or restore the database — it works with the in-memory frontend cache.

11. Validation Rules
11.1 Client-side (Form)
Field	Rule
code	Must not be empty (trimmed)
typeId	Must be selected
regionId	Must be selected
Images	Max 20 per property; max 8MB each; JPEG/PNG/WEBP only
Phone numbers	Max 5 per property
11.2 Import Validation (client)
A parsed row is discarded if all of the following are empty/zero: price, area, code, title.

11.3 Server-side (API)
All routes use Zod schema validation generated from Drizzle schema via drizzle-zod:

Route	Schema
POST /api/properties	insertPropertySchema (full)
PATCH /api/properties/:id	insertPropertySchema.partial()
POST /api/properties/import	z.array(insertPropertySchema)
PATCH /api/properties/bulk	z.object({ ids: string[], updates: insertPropertySchema.partial() })
DELETE /api/properties/bulk	z.object({ ids: z.array(z.string()).min(1) })
Failed validation returns HTTP 400 with { error: string }.

11.4 Number Parsing Rules (propertyImport.ts)
Arabic digits (٠-٩) are converted to Western digits before parsing
Arabic decimal separator (٫) → .
Arabic thousands separator (٬) → removed
Price: Handles مليون (×1,000,000) and ألف/الف (×1,000) unit suffixes; handles thousands-separator dots (e.g. 1.500.000 → 1500000); takes first segment when | or newline separates multiple values
Area: Extracts first numeric sequence; rounds to integer
Floor: أرضي/ارضي → 0; first number otherwise
Layout beds/baths: Regex (\d+)\s*غر for bedrooms, (\d+)\s*حمام for bathrooms
12. Public vs. Staff API Access
The GET /api/properties endpoint has dual behavior:

Caller	Behavior
Unauthenticated visitor	Returns only status = "active" rows; strips source, agentType, sourcePhones, sourceEmail, sourceLocation, sourceNotes
Authenticated staff (admin/agent)	Returns all rows with all fields
This ensures source/broker data is never exposed to the public.
