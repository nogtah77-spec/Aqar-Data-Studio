# Project Vision — Aqar Data Studio

## What It Is

Aqar Data Studio is a professional SaaS platform for real estate data management. It is designed to be sold to any real estate company, developer, or agency — not tied to any single brand.

## Who It's For

- Real estate agencies managing hundreds or thousands of listings
- Property developers tracking unit inventory
- Marketing companies handling multiple clients' properties
- Any organization that needs to import, enrich, manage, and export real estate data at scale

## Core Values

1. **Dynamic over hard-coded**: Every dropdown, status, region, and classification is manageable from the admin panel without code changes
2. **Bilingual by design**: Arabic-first with full English support; RTL layout native
3. **Import-friendly**: The best import engine possible — tolerant of messy data, smart about column detection, preview-before-commit
4. **Audit-everything**: Every write operation is logged with before/after snapshots
5. **White-label ready**: Company name, logo, colors, and defaults are all configurable per instance

## What Makes It Different

- **Smart Text Parser**: Paste "شقة 170 متر بالشروق نصف تشطيب 3 غرف" and it auto-fills the form
- **Version History**: Every property change is versioned — roll back to any previous state
- **Bulk Power**: Select 500 properties, change status, reassign region, export — all in one flow
- **Export Flexibility**: Choose format, columns, filters, and sort order per export

## What It Is NOT

- A public-facing property listing website (this is the backend management tool)
- A CRM (no client tracking, deal pipeline, or lead management — these are future modules)
- Tied to any geography (regions, types, and values are fully configurable)
